# 4D Tesseract Simulator

**Author:** Joe Nasr  
**Canonical identity:** https://joe-nasr-signals.vercel.app/v2/

A browser visualization for exploring rotations of a tesseract through a projected view controlled with rotation sliders.

## Status

Interactive visualization prototype.

The project is intended to help inspect the geometry of a four dimensional hypercube through lower dimensional projection. It is a mathematical visualization, not a physical simulation of four dimensional space and not evidence that four dimensional physical motion has been reproduced.

Live build: https://joenasriani.github.io/4d-tesseract-simulator/
